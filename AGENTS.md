# Project Rules

- Todo o desenvolvimento futuro e qualquer código solicitado devem ser baseados estritamente na estrutura atual de restauração do projeto (Angochat), preservando as dependências, a integração com Supabase, o suporte ao Capacitor e plugins cordova existentes.
- Não mexer na pasta `resources` a menos que seja explicitamente solicitado pelo usuário.
- Manter a configuração do `InAppBrowser` em background (hidden=yes) como base para o desenvolvimento do Feed.tsx.
